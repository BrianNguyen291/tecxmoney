# TecxMoney

Personal-finance micro-lessons for high-inflation, mobile-money markets.
Learn a screen, then test it: true/false swipe cards, then multiple choice.

Live: https://briannguyen291.github.io/tecxmoney/

## Content

Four lessons written from scratch — inflation, compounding both ways, where money
can live, and how a scam is built. **No book was copied or scraped.** The source
reading list was used only to scope topics; every word here is original, and the
worked figures are illustrative.

Context is deliberately African rather than American: mobile wallets, loan-app
APRs, SACCOs, chamas/stokvels/susu, treasury bills and money market funds — not
401(k)s and the S&P 500.

Lessons are data (`src/content/*.ts`), so adding one is authoring, not engineering.

```
pnpm install && pnpm dev
```
